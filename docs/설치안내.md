# 부대찌개반 대화방 설치 안내서

선생님 혼자 따라 할 수 있도록 한 단계에 한 동작씩 적었어요. 비용은 들지 않아요(Firebase 무료 요금제, 신용카드 등록 없음).

---

## 0. 먼저 내 컴퓨터에서 미리 보기 (선택)

인터넷에 올리기 전에 내 컴퓨터에서 가짜 데이터로 화면을 볼 수 있어요.

1. 이 폴더에서 터미널(명령 프롬프트)을 엽니다.
2. 처음 한 번만: `npm install`
3. `npm run preview:local`
4. 잠시 뒤 `Local: http://localhost:5173/`이 보이면 브라우저에서 엽니다.
   - 학생 화면: `http://localhost:5173/` → **김가은 / 이시우 / 최유나**는 암호 `1234`, **박서준 / 정예준**은 처음 가입하는 학생이에요.
   - 선생님 화면: `http://localhost:5173/teacher` → "구글 계정으로 로그인" → 뜨는 창에서 **Add new account** → 이메일에 `teacher@test.com` → **Sign in**
   - 같은 와이파이의 핸드폰에서는 터미널에 보이는 `Network: http://192.168.x.x:5173/` 주소로 열 수 있어요.
5. 끝낼 때는 터미널에서 `Ctrl + C`. 미리 보기 데이터는 끌 때 사라져요.

> 미리 보기를 하려면 Java가 필요해요. `java -version`이 안 되면 `winget install EclipseAdoptium.Temurin.21.JDK`로 설치하고 터미널을 새로 여세요.

---

## 1. 준비물 확인

1. Node.js가 있는지 확인합니다: 터미널에서 `node -v` → `v20` 이상이 보이면 됩니다.
   없으면 https://nodejs.org 에서 **LTS** 버전을 받아 설치하세요.
2. 이 폴더에서 `npm install`을 한 번 실행합니다.

## 2. Firebase 프로젝트 만들기

1. https://console.firebase.google.com 에 **선생님 구글 계정**으로 들어갑니다.
2. **프로젝트 추가** → 이름은 예: `budae-chat` → 계속.
3. **Google 애널리틱스는 끕니다** → 프로젝트 만들기.
4. 요금제는 **Spark(무료)** 그대로 둡니다. 업그레이드하지 않아도 돼요.
5. 프로젝트 설정(⚙️)에서 **프로젝트 ID**를 적어 둡니다. (예: `budae-chat-1a2b3`)

## 3. 로그인 방법 켜기

1. 왼쪽 메뉴 **빌드 → Authentication → 시작하기**.
2. **로그인 방법** 탭에서 **Google**을 눌러 사용 설정 → 지원 이메일에 선생님 메일 → 저장.
3. 다시 **새 제공업체 추가 → 이메일/비밀번호** → 첫 번째 스위치만 켜고 저장.
   (학생 계정에 쓰여요. 학생은 이메일이 없어도 돼요.)

## 4. 데이터베이스 두 개 만들기

1. **빌드 → Firestore Database → 데이터베이스 만들기**
   - 위치: **asia-northeast3 (서울)**
   - **프로덕션 모드**로 시작 (규칙은 9단계에서 자동으로 올라가요)
2. **빌드 → Realtime Database → 데이터베이스 만들기**
   - 위치: 가까운 곳(예: 싱가포르 `asia-southeast1`)
   - **잠금 모드**로 시작

## 5. 웹 앱 등록하고 설정값 복사

1. 프로젝트 개요 옆 ⚙️ → **프로젝트 설정** → 아래쪽 **내 앱** → **</>(웹)** 아이콘.
2. 앱 닉네임 아무거나(예: `budae-web`), **Firebase 호스팅도 설정**은 체크하지 않아도 돼요 → 앱 등록.
3. 화면에 나오는 `firebaseConfig = { ... }` 안의 값들을 메모장에 그대로 복사해 둡니다.
   (`apiKey`, `authDomain`, `databaseURL`, `projectId`, `storageBucket`, `messagingSenderId`, `appId`)
   - `databaseURL`이 안 보이면 4단계의 Realtime Database 화면 위쪽에 있는 `https://...firebasedatabase.app` 주소를 쓰세요.

## 6. Firebase에 로그인

터미널에서:

```
npx firebase login
```

브라우저가 열리면 **선생님 구글 계정**으로 허용합니다.

## 7. 설정 파일 만들기

터미널에서 (이메일과 프로젝트 ID는 내 것으로 바꿔서):

```
node scripts/configure.mjs --teacher 선생님메일@gmail.com --project budae-chat-1a2b3
```

질문이 하나씩 나오면 5단계에서 복사해 둔 값을 붙여 넣고 Enter를 누릅니다.
`configure: firestore.rules, .firebaserc, .env.local (...)`이 보이면 성공이에요.

> 이 선생님 메일로 로그인한 사람만 방을 만들고 학생을 관리할 수 있어요. 다른 구글 계정은 "방을 만들 권한이 없어요"만 봐요.

## 8. 호스팅 켜기 (처음 한 번)

Firebase 콘솔 왼쪽 메뉴 **빌드 → Hosting → 시작하기**를 눌러 안내 화면을 끝까지 넘깁니다(명령어는 따라 하지 않아도 돼요).

## 9. 인터넷에 올리기

```
npm run deploy
```

끝나면 `Hosting URL: https://budae-chat-1a2b3.web.app`처럼 주소가 나와요. 이 주소가 학생들에게 나눠 줄 **링크**예요.

## 10. 처음 쓰기

1. `https://(내 주소)/teacher`를 열고 **구글 계정으로 로그인**.
2. **📋 반 명단** 탭에 학생 이름을 한 줄에 한 명씩 붙여 넣고 **명단에 넣기**.
   - 실명 대신 이름만 쓰거나 별명을 써도 돼요.
3. **🍲 냄비** 탭 → **＋ 새 냄비 만들기** → 이름, 이모지, 참여 학생 고르기.
4. 오른쪽 위 **🔗 참여 링크 복사**로 학생들에게 링크를 보냅니다.
5. 학생은 링크에서 자기 이름을 고르고, 처음 한 번 재료와 암호(4자리 이상)를 정해요.

## 운영 팁

- **불 끄기**: 냄비 안 오른쪽(핸드폰은 위쪽 스위치)에서 바로 끄고 켤 수 있어요. 매일 22:00~07:00에는 자동으로 꺼져요(시간 바꾸기·끄기 가능). 직접 바꾼 상태는 다음 자동 전환 시각까지 유지돼요.
- **추방**: 냄비 안 학생 이름 옆 **⋯ → 추방하기**. 그 냄비에서만 나가고, "추방됨 · 풀기"로 되돌릴 수 있어요.
- **명단에서 삭제**: 전학처럼 아예 빠질 때만. 모든 냄비에서 빠지고 지난 메시지는 남아요.
- **메시지 삭제**: 학생 메시지 옆 🗑. 학생들에게는 "주방장이 건져낸 메시지예요"로 보여요.
- **욕설**: 자동으로 ＊로 가려지고, 원래 문장은 **⚠️ 경고 기록**에서 선생님만 봐요. 반에서 따로 막을 말은 **⚙️ 설정 → 금지어**에 넣으세요. 모든 표현을 완벽하게 잡지는 못해요.

## 자주 막히는 곳

| 증상 | 해결 |
|---|---|
| 구글 로그인 창이 안 떠요 | 브라우저 주소창 오른쪽의 **팝업 차단**을 허용하세요. |
| 로그인하면 `auth/unauthorized-domain` | Authentication → **설정 → 승인된 도메인**에 내 주소(`...web.app`)가 있는지 확인하세요. |
| "방을 만들 권한이 없어요" | 7단계에서 넣은 선생님 메일과 로그인한 구글 계정이 같은지 확인하고, 다르면 7단계와 9단계를 다시 하세요. |
| 학생이 암호를 잊었어요 | **📋 반 명단 → 🔑 암호 초기화**. 학생은 다음에 들어올 때 새 암호를 정해요. |
| 다른 친구가 이름을 먼저 가져갔어요 | 그 이름을 **암호 초기화**하고 진짜 주인이 다시 가입하게 하세요. 장난친 학생은 추방할 수 있어요. |
| 코드를 고친 뒤 반영이 안 돼요 | `npm run deploy`를 다시 실행하세요. |
