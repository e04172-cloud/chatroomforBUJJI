# 부대찌개반 대화방 설계 문서

작성일: 2026-10-21
화면 시안: [2026-10-21-budae-chat-mockup.html](2026-10-21-budae-chat-mockup.html) (브라우저로 열기)

## 1. 무엇을, 왜

초등(추정) 담임선생님 한 분이 자기 반 학생 26명과 쓰는 카카오톡 같은 웹 대화방이다. 반 이름이 "부대찌개반"이라 전체 디자인 콘셉트가 부대찌개다.

- 설치 없이 브라우저로 쓴다. 학생은 각자 개인 노트북이 있고, 개인 핸드폰으로도 들어온다. 학교 밖과 집에서도 쓴다.
- 선생님이 방을 만들고 링크를 공유하면 학생이 들어온다.
- 선생님은 학생을 통제할 수 있어야 한다: 추방, 메시지 삭제, 방 전체 대화 중단(냄비 불 끄기), 욕설 가리기.
- 사용자는 기술을 잘 모른다. 설치·배포 과정은 단계별로 따라 할 수 있어야 한다.

성공 기준: 선생님이 혼자 배포해서 링크를 나눠주고, 학생 26명이 각자 이름으로 들어와 대화하며, 선생님이 밤에는 불을 꺼 두고 문제 학생과 문제 메시지를 정리할 수 있다.

## 2. 목표 / 비목표 / 반목표

**목표**
- 명단 기반 학생 계정(한 사람 = 이름 하나), 노트북·핸드폰 어디서든 같은 계정
- 선생님 1명이 여러 방 운영(반 전체 방 + 일부 학생만 들어가는 방)
- 추방/풀기, 메시지 삭제, 불 끄기/켜기(수동 + 자동 시간), 욕설 마스킹과 경고
- 부대찌개 콘셉트의 깔끔하고 재미있는 디자인, 재료 이모지 프로필

**비목표** (이번에 만들지 않음)
- 다른 선생님이 쓰는 기능(다중 운영자, 회원가입)
- 사진·파일 전송, 음성, 메시지 수정, 답장/반응 기능
- 핸드폰 푸시 알림(안 읽은 수 표시만 함)
- 앱 설치(PWA 설치 유도 포함)

**반목표** (기술적으로 돌아가도 이러면 실패)
- 학생이 다른 이름으로 부계정을 만들거나, 이미 가입한 친구 이름으로 로그인할 수 있다(아직 가입하지 않은 이름을 먼저 가져가는 것은 받아들인 위험, 4.1 참고)
- 학생이 선생님 권한(불 켜기, 추방 해제, 삭제, 방 만들기)을 화면 조작으로 얻을 수 있다. **권한은 반드시 서버(보안 규칙)에서 확인한다.**
- 학교 교실처럼 여러 기기가 같은 IP로 보이는 환경에서 접속이 막힌다(IP로 사람을 구분하지 않는다)
- 디자인이 콘셉트 때문에 지저분해진다
- 선생님이 설정하다 막혀서 포기한다

## 3. 제약

- 운영자는 선생님 한 명. 학생 약 26~30명, 방은 몇 개 수준.
- 비용은 무료여야 한다. **(Claude 판단)** 신용카드 등록이 필요 없는 Firebase 무료(Spark) 요금제 안에서 동작하게 한다. 따라서 Cloud Functions(유료 요금제 필요)를 쓰지 않고, 권한 확인은 Firestore/Realtime Database 보안 규칙으로 한다.
- 화면은 노트북과 핸드폰 둘 다 잘 보여야 한다(반응형).
- 한국어 UI. 시간대는 한국 시간(KST).

## 4. 사용자가 정한 것

### 4.1 학생 계정: 명단 방식
- 선생님이 **반 명단**에 학생 이름을 미리 넣는다. 운영 중에 추가·삭제할 수 있다.
- 학생은 링크로 들어와 명단에서 자기 이름을 고르고, 처음 한 번 **암호**를 정한다.
- 이미 가입한 이름은 ✔ 표시가 붙고, 누르면 암호만 묻는다. 그래서 노트북·핸드폰 어디서든 같은 이름으로 들어온다.
- 명단에 없는 이름은 만들 수 없다. 브라우저를 바꿔도 부계정이 생기지 않는다.
- 같은 기기에서 다시 오면 이름이 미리 선택돼 있다(브라우저 저장, 편의 기능일 뿐).
- 선생님은 학생별로 **암호 초기화**를 할 수 있다(학생이 잊었거나 다른 학생이 먼저 가져갔을 때).
- **첫 가입에 별도 확인 코드는 없다(사용자 결정).** 링크만 있으면 아직 가입하지 않은 이름을 고를 수 있고, 로그인 전 입장 화면에서 명단 이름이 보인다. 링크가 외부로 퍼지거나 친구가 이름을 먼저 가져갈 위험은 사용자가 알고 받아들였다. 대응은 선생님의 암호 초기화와 추방이다.
- **명단 이름은 선생님이 입력한 그대로** 쓴다. 실명을 넣을지 별명을 넣을지는 선생님이 정한다(사용자 결정). 설치 안내서에 "실명 대신 이름만, 별명 등을 써도 된다"는 안내를 한 줄 넣는다.
- 한 학생이 기기 여러 대로 동시에 접속해도 인원수·접속자 수는 **사람 기준 1명**이다.

### 4.2 선생님 구분
- 선생님은 별도 선생님 화면에서 **구글 계정 로그인**을 한다.
- 미리 등록된 선생님 구글 계정만 운영자다. 방 만들기/지우기, 반 명단 관리는 이 계정만 할 수 있다. 다른 구글 계정은 "방을 만들 권한이 없어요"만 본다.
- 학생 입장 화면에서는 선생님을 고를 수 없다.

### 4.3 방
- 선생님은 방을 여러 개 만들 수 있다. 방마다 이름과 대표 이모지를 정한다.
- 방을 만들 때 반 명단에서 참여 학생을 고른다. 운영 중에도 방마다 학생을 넣고 뺄 수 있다.
- 학생 계정은 하나다. 이름, 암호, 재료 이모지는 모든 방에서 같다.
- **링크는 하나**다. 학생이 로그인하면 자기가 들어가 있는 **방 목록**이 나온다(방 이름, 인원, 불 상태, 안 읽은 수). 자기가 속하지 않은 방은 보이지도 않고 들어갈 수도 없다(서버에서 확인).

### 4.4 선생님 통제 기능 (방마다 따로)
- **추방 / 풀기**: 추방하면 그 학생은 그 방에서 즉시 나가고 풀어줄 때까지 못 들어온다. 명단에는 "추방됨 · 풀기"로 남고, 지난 메시지도 남는다. 다른 방에는 영향이 없다.
- **명단에서 삭제**: 반 명단에서 완전히 지운다(전학 같은 경우). 추방과는 다른 기능이다.
- **메시지 삭제**: 선생님은 아무 메시지나 삭제할 수 있다. 학생들에게는 "주방장이 건져낸 메시지예요"로 보인다.
- **냄비 불 끄기/켜기**(원래 "얼음" 기능): 불을 끄면 그 방 전체에 쓰기가 막힌다.
  - 학생 화면: 국물색 띠가 식은 회갈색으로 바뀌고 "💤 불 꺼짐"이 표시된다. "주방장이 냄비 불을 껐어요" 안내가 뜨고 입력창이 잠긴다. 지난 대화는 읽을 수 있다.
  - **자동 불 끄기 시간**: 선생님이 끌 시각과 켤 시각을 정한다. 처음 값은 22:00~07:00이고 매일 적용된다.
  - 자동으로 꺼진 시간에도 선생님은 직접 켜거나 끌 수 있고, 직접 바꾼 게 우선이다.
  - 꺼져 있을 때 학생 화면에 다시 켜지는 시각을 알려준다.

### 4.5 욕설·부적절한 말
- 욕설·비속어는 `＊`로 가려서 보인다.
- 부적절한 말을 쓴 학생에게만 경고가 뜬다: "⚠️ 국물이 탁해져요! 바르고 고운 말을 써요. 부적절한 표현은 가려서 보냈어요."
- **선생님은 원래 문장을 본다(사용자 결정).** 학생들에게는 가려진 문장이 보이고, 선생님 화면의 대화에서는 원래 문장이 보인다. 걸린 단어는 강조 표시하고 "가려짐" 표시를 붙인다(표시 방식은 Claude 판단).
- **경고 기록(사용자 요청)**: 선생님 화면에서 경고가 뜬 메시지만 모아 본다. 시간, 학생, 방, 원래 문장, 가려진 문장이 나온다. 학생별로 걸러 볼 수 있다. 원래 문장은 **선생님만 읽을 수 있는 별도 저장소**에 둔다. 학생이 읽을 수 있는 메시지 문서에는 원래 문장을 절대 넣지 않는다(Firestore는 필드 단위로 읽기를 숨길 수 없기 때문).
- 한국어 욕설 목록을 기본으로 넣고, 띄어쓰기나 특수문자를 섞은 변형도 어느 정도 잡는다. 선생님이 금지어를 직접 추가할 수 있다. 완벽하게 다 잡을 수 없다는 점은 사용자에게 이미 설명했다.

### 4.6 디자인
- 콘셉트는 부대찌개. 깔끔하게, 지저분하지 않게.
- 색: 국물 빨강(주인공 색, 내 말풍선, 버튼), 치즈 노랑(선생님 표시와 선생님 말풍선), 대파 초록(접속 표시), 따뜻한 크림색 바탕. 정확한 값은 시안 CSS 변수를 따른다.
- 방 위쪽은 냄비처럼 국물색 띠로 만들고, 아래 끝을 물결 모양으로 처리한다. 불이 켜져 있으면 "🔥 ○명 보글보글"이 표시되고 🔥가 살짝 일렁인다.
- 선생님 표시는 "🧑‍🍳 주방장" 배지. 입장 버튼은 "냄비에 퐁당! 입장하기". 장난스러운 말투를 쓴다.
- **재료 이모지 프로필 30가지, 한 묶음**으로 보여준다(정통과 이상한 재료를 나누지 않음). 여러 학생이 같은 재료를 골라도 되고, 입장 뒤에도 바꿀 수 있다. 이름 옆에 재료 이름이 작게 붙는다.
  - 🌭소시지 🥫스팸 🍜라면사리 🧀치즈 🥬김치 🌶️고추 🫘베이크드빈 🥓베이컨 🍄버섯 🧅양파 🍡떡사리 🥟만두 🍢어묵 🧄마늘 🥚계란 🧈두부
  - 🍫초콜릿 🍬젤리 🍭막대사탕 🍎사과 🍓딸기 🍌바나나 🍉수박 🍍파인애플 🍦아이스크림 🍩도넛 🧁컵케이크 🍪쿠키 🍕피자 🥤콜라
- **"오늘의 부대찌개" 줄**: 방 위쪽에 그 방 학생들이 고른 재료와 개수를 보여준다(많은 순, 몇 개만 보이고 "외 ○종"). 정통 재료가 아닌 것의 비율에 따라 맛 평가가 😋 → 🤔 → 🤢로 바뀐다. 내부적으로는 재료마다 정통 여부를 갖고 있지만 고르는 화면에서는 나누지 않는다.
- 이상한 재료로 들어오면 입장 안내에 "…괜찮을까?" 같은 한마디가 붙는다.

### 4.6.1 모바일 화면 (사용자가 특히 강조함)
학생들이 개인 핸드폰으로도 들어오므로, **핸드폰 브라우저에서 비율이 깨지거나 잘리는 곳이 없어야 한다.** 시안은 노트북 기준이므로 모바일 배치는 아래 기준으로 다시 맞춘다.
- 기준 폭 360px(작은 안드로이드)부터 큰 화면까지. 가로 스크롤이 생기면 안 된다.
- 대화 화면은 화면 높이에 꽉 차게(`100dvh` 등). 키보드가 올라와도 **입력창이 가려지지 않고**, 위쪽 냄비 띠와 입력창은 고정, 대화 목록만 스크롤된다. 아이폰 노치·홈 바 영역(safe area)을 고려한다.
- 입장 화면의 이름 칸과 재료 30개 칸은 작은 화면에서도 손가락으로 누르기 충분한 크기(최소 약 44px)로, 줄 수를 줄여 배치한다. 재료 이름 글자가 잘리지 않게 한다.
- "오늘의 부대찌개" 줄은 좁은 화면에서 한 줄로 줄이고 가로로 넘기거나 개수를 줄여 보여준다. 두 줄 이상으로 늘어나 대화 영역을 잡아먹지 않게 한다.
- 선생님 화면을 핸드폰에서 볼 때는 오른쪽 명단 패널을 **아래에서 올라오는 시트나 별도 탭**으로 바꾼다. 불 스위치는 핸드폰에서도 한 번에 닿는 위치에 둔다.
- 말풍선은 긴 단어나 링크가 화면 밖으로 넘치지 않게 줄바꿈한다.
- 완료 전에 실제 모바일 크기(360×740, 390×844)와 노트북 크기에서 모든 화면을 눈으로 확인한다.

### 4.7 기술 선택 (Claude가 정했고 사용자가 받아들임)
- Firebase 사용: Hosting(웹 주소), Authentication, Firestore(필요하면 접속 표시에 Realtime Database).
- 선생님이 구글 계정으로 Firebase 프로젝트를 한 번 만들고 배포한다. **선생님용 단계별 설치·배포 안내서**를 함께 만든다(화면 캡처 수준으로 쉽게).

## 5. Claude가 정한 것 (사용자가 따로 확인하지 않은 부분)

- **학생 로그인 구현**: 학생은 이메일이 없으므로, 명단 항목마다 내부용 가짜 이메일(예: `<학생ID>-<세대번호>@budae.invalid`)을 만들어 Firebase 이메일/비밀번호 인증을 쓴다. 이미 가입된 이름은 Auth 계정이 이미 있어서 가입이 실패하므로, 이름 선점 확인이 서버 쪽에서 된다. 암호 초기화는 세대번호를 올려서 새 계정을 받게 하고, 보안 규칙은 현재 세대 계정만 인정한다(관리자 SDK 없이 무료 요금제에서 가능). 더 나은 방법이 있으면 빌더가 바꿔도 되지만 "무료, 서버에서 확인"은 지켜야 한다.
- **암호 규칙**: 최소 4자리(초등학생 기준). 반복해서 틀리면 Firebase Auth의 기본 차단 장치로 막는다.
- **욕설 필터 위치**: 보내기 전에 화면에서 가리고 경고한다. 화면을 조작해 그대로 보내는 경우를 막기 위해 보안 규칙에서도 기본 금지어 패턴이 들어간 메시지를 거절한다(가능한 범위에서).
- **도배 방지**: 한 학생이 아주 짧은 간격으로 계속 보내지 못하게 한다(예: 1초에 1개). 메시지 최대 길이 500자.
- **선생님 수동 불 조작의 지속 시간**: 선생님이 직접 켜거나 끈 상태는 **다음 자동 전환 시각까지만** 유지된다. 예: 23:00에 직접 켜면 07:00까지 켜져 있고(자동 켜짐 시각이라 그대로), 그날 22:00에는 다시 자동으로 꺼진다. 낮에 직접 끄면 22:00 자동 꺼짐 이후 07:00에 자동으로 켜진다. 자동 시간 기능을 끄는 옵션도 둔다.
- **자동 불 끄기 판단**: 서버 시간(보안 규칙의 `request.time`)을 한국 시간으로 바꿔 판단한다. 학생 기기 시계를 믿지 않는다.
- **명단 삭제된 학생의 지난 메시지**: 이름과 재료 그대로 남긴다.
- **학생은 자기 메시지를 지울 수 없다.** 삭제는 선생님만.
- **메시지 보관**: 기한 없이 보관. 선생님이 방을 지우면 그 방 메시지도 지운다.
- **선생님 이름**: 기본 "담임선생님", 선생님이 바꿀 수 있다. 프로필은 🧑‍🍳.
- **추방된 학생 화면**: 그 방 목록에 "이 냄비에서 잠시 나와 있어요"로 보이고 들어갈 수 없다.
- 시스템 안내(입장, 불 꺼짐/켜짐)는 대화 사이에 작게 표시한다. 입장 안내는 처음 가입할 때만 띄운다(매번 들어올 때마다 띄우면 시끄럽다).

## 6. 빌더에게 맡기는 것

- 프런트엔드 프레임워크 선택(정적 호스팅이 가능한 것), 폴더 구조
- Firestore 데이터 구조와 보안 규칙의 세부 작성(위 반목표를 지키는 범위에서)
- 접속자 수(보글보글 인원) 구현 방식
- 기본 욕설 목록 작성과 변형 탐지 방식
- 맛 평가 단계의 정확한 비율 기준
- 시안에 없는 화면(선생님 방 만들기, 반 명단 관리, 자동 시간 설정 화면)의 세부 배치. 시안의 디자인 언어를 따른다.
- 테스트 전략. 단, 보안 규칙은 에뮬레이터로 반드시 테스트한다(학생이 선생님 기능을 못 쓰는지, 다른 방을 못 읽는지, 불 꺼진 방에 못 쓰는지, 추방 상태에서 못 쓰는지).
